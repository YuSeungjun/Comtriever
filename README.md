# Comtriever

Comtriever는 macOS 데스크탑 위에서 함께 움직이는 작은 리트리버 반려 앱입니다. 작업 중인 화면 위에 강아지가 나타나고, 메뉴 막대에서 설정을 열거나 리트리버를 집으로 보내고 다시 부를 수 있습니다.

## 다운로드 및 설치

[최신 comtrierver.dmg 다운로드](https://github.com/YuSeungjun/Comtriever/releases/latest/download/comtrierver.dmg)

Apple Silicon과 Intel Mac 공용 설치 파일입니다. 처음 사용하는 Mac에서는 1레벨 `첫 만남`으로 시작하고, 기존 사용자는 저장된 경험치와 설정을 이어서 사용합니다.

1. 다운로드한 DMG 파일을 엽니다.
2. `Comtriever.app`을 `Applications` 폴더로 드래그합니다.
3. `Applications` 폴더에서 `Comtriever.app`을 실행합니다.
4. 처음 실행할 때 macOS가 차단하면 `Comtriever.app`을 우클릭한 뒤 `열기`를 누릅니다.
5. 그래도 차단되면 `시스템 설정 > 개인정보 보호 및 보안`에서 `그래도 열기`를 누릅니다.

처음 한 번만 허용하면 이후에는 일반 앱처럼 실행됩니다.

## macOS 보안 경고 안내

현재 배포 파일은 무료 MVP/테스트 배포용 unsigned 빌드입니다. Apple Developer ID 서명과 공증을 하지 않았기 때문에 macOS에서 다음과 같은 경고가 나올 수 있습니다.

- "`Comtriever`을(를) 열지 않음"
- "Apple은 악성 코드가 없는지 확인할 수 없습니다"
- "확인되지 않은 개발자"

이 경고는 앱이 악성이라는 뜻이 아니라, Apple 유료 개발자 계정으로 서명 및 공증된 앱이 아니라는 뜻입니다. 비용 없는 공개 테스트 배포에서는 이 경고를 완전히 없앨 수 없습니다.

## 주요 기능

- 데스크탑 위에 리트리버 캐릭터가 표시됩니다.
- 리트리버가 대기, 걷기, 다시 등장, 기쁨, 잠자기 애니메이션을 재생합니다.
- 메뉴 막대 아이콘에서 설정 창을 열 수 있습니다.
- 트레이 아이콘을 누르면 메뉴만 열립니다. 메뉴에는 `설정 열기`, 상태에 따라 바뀌는 `집으로 보내기` 또는 `다시 부르기`, `Comtriever 종료`만 표시됩니다.
- `리트리버 집으로 보내기`로 화면에서 잠시 숨길 수 있습니다.
- `다시 부르기`로 리트리버를 다시 나타나게 할 수 있습니다.
- `항상 위에 표시`로 다른 앱 위에 리트리버를 유지할 수 있습니다.
- `작업창 가리지 않기`로 작업 중인 창을 방해하지 않게 할 수 있습니다.
- 마지막 표시 상태, 위치, 표시 모드가 저장됩니다.
- macOS 로그인 시 자동 실행을 설정할 수 있습니다.
- 머리·몸·배를 누른 채 문지르면 부위에 맞게 반응하고 친밀도가 쌓입니다.
- 가만히 0.4초 누른 뒤 옮겨 놓으면 이동 속도에 따라 날아가고, 중력과 화면 가장자리 충돌로 착지합니다.
- 간식을 던지면 찾아가 먹고, 공은 주운 자리에서 물고 기다립니다. 입 앞의 공을 잡아 다시 던지며 계속 놀 수 있습니다.
- 한 번·매일·매주 일정을 등록하고, 알림에서 완료하거나 10분 미룰 수 있습니다.
- 교감 경험치, 친밀도 레벨, 배고픔 게이지와 일정이 기존 설정과 함께 저장됩니다.
- 친밀도는 최대 8레벨입니다. 누적 경험치 기준으로 첫 만남(0) → 낯익은 사이(25) → 반가운 친구(100) → 가까운 친구(225) → 든든한 친구(400) → 소중한 단짝(800) → 가족 같은 사이(1,500) → 평생의 가족(2,500) 순서로 가까워집니다. 최고 레벨에서도 경험치와 함께한 활동 기록은 계속 저장됩니다.
- 안아줄 때 이동 속도·흔들림·시간에 따라 편안함, 놀람, 내려가고 싶은 감정을 표현합니다.
- 다른 앱 창 윗부분에 내려놓으면 그 위에서 쉬고 산책합니다. 창 이동을 따라가고, 최소화·닫힘·가림으로 발판이 사라지면 내려옵니다.
- 2분 이상 자리를 비웠다 돌아오면 반겨줍니다. 화면 잠금과 잠자기가 겹쳐도 한 번만 인사합니다.

## 함께 놀기와 일정

설정 창의 **함께하기**에서 간식·공놀이와 친밀도를, **일정**에서 알림을 관리합니다. 리트리버에 마우스를 올리면 작은 놀이 메뉴가 나타나며, 우클릭하면 메뉴를 고정할 수 있습니다. 놀이 중에는 `그만` 버튼으로 멈출 수 있습니다.

강아지 주변의 투명한 여백은 클릭을 통과시켜 뒤에 있는 폴더나 창을 바로 누를 수 있습니다. 실제 캐릭터 그림과 표시된 메뉴·알림만 마우스 입력을 받고, 강아지를 누르고 있는 동안은 포인터가 그림 밖으로 나가도 쓰다듬기·드래그를 이어갑니다.

쓰다듬기는 누른 직후 문지르고, 이동은 제자리에서 0.4초 누른 뒤 시작합니다. 간식을 먹으면 강아지 꼬리 쪽에 세로 배고픔 게이지가 약 3초 동안 나타나고, 먹기 전 수치부터 회복된 수치까지 초록색 게이지와 퍼센트가 부드럽게 올라갑니다. 게이지는 함께 있는 동안 앱을 꺼둔 시간을 포함해 1분에 1%p씩 줄어듭니다. 집으로 보내면 남은 수치를 유지하고, 쉬는 상태에서 앱을 다시 실행해도 줄어들지 않습니다. 다시 부른 시점부터 감소가 재개됩니다. 메인 화면도 누워 쉬는 그림과 “나 잠시 쉬고 있어” 문구로 바뀝니다. 친밀도 보상에는 짧은 대기 시간이 있어 연속 입력으로 경험치가 과도하게 쌓이지 않습니다.

공을 주울 때마다 그 자리에서 기다리며 배고픔 게이지가 추가로 5%p 줄어듭니다. 꼬리 쪽의 세로 게이지가 노란색으로 바뀌고 퍼센트와 함께 줄어든 수치까지 부드럽게 내려가며, 마지막 0%도 표시합니다. 보상 대기 시간 중에도 매번 차감하며, 0%가 되면 배고프다는 말과 함께 공놀이를 끝냅니다. 간식을 먹으면 다시 놀 수 있습니다. 공을 들고 기다리거나 사용자가 공을 잡고 있는 동안에도 놀이가 유지되며, 놀이 중에는 강아지 메뉴와 설정창의 간식·공놀이 버튼이 비활성화되고 `그만`만 사용할 수 있습니다.

일정은 앱이 실행 중일 때 확인합니다. 앱 종료나 Mac 잠자기 중 놓친 일정은 다음 실행·복귀 때 표시합니다. 반복 일정은 완료하면 원래 정한 시각의 다음 일정으로 넘어갑니다. macOS 알림의 표시는 앱 서명과 시스템 알림 설정에 따라 달라지며, 앱 안에서도 일정 카드와 확인할 일정을 볼 수 있습니다.

캐릭터는 화면 갱신에 맞춰 애니메이션을 재생하고, 이동 속도에 맞춘 걸음·숨쉬기·기울기·착지 효과를 적용합니다. 기존 그림 프레임을 사용하므로 원화의 중간 동작이 새로 생성되는 것은 아닙니다. 안아줄 때 감정 표현, 부드러운 몸 움직임, 놓았을 때 떨어지는 물리는 항상 동작하는 기본 기능이며 별도의 끄기 설정은 없습니다. 이전 버전에서 꺼둔 경우에도 자동으로 적용됩니다.

**안아주기**는 가만히 0.4초 누른 뒤 시작합니다. 살살 안고 있으면 편안해하고, 빠르게 좌우로 흔들면 놀랍니다. 8초 이상 들고 있으면 내려가고 싶다는 반응을 보입니다. 친밀도를 깎거나 벌점을 주지는 않습니다.

**창 위에 앉히기**는 두 표시 방식 모두에서 창 윗부분보다 높이 들어 올려 놓으면 됩니다. `창 위에서 쉬고 걷기`는 기본으로 켜져 있고, `혼자 산책하기`를 켜면 발판 안에서 걷습니다. `작업창 가리지 않기`에서는 잡아서 옮기거나 창 위에 머무는 동안만 잠시 앞으로 표시하고, 떨어지거나 내려놓으면 원래 표시 방식으로 돌아갑니다. 선택한 표시 방식은 자동으로 바뀌거나 저장되지 않습니다. 캐릭터 전체가 들어갈 윗공간과 발을 디딜 충분한 너비가 필요하며, 다른 창에 가려진 부분이나 화면 맨 위처럼 머리가 잘리는 위치는 발판으로 쓰지 않습니다.

발을 창 윗가장자리 가까이에 살며시 놓으면 높이가 조금 어긋나도 맞춰 앉습니다. 빠르게 던지면 기존 물리 효과가 유지됩니다. 창이 닫히거나 최소화되거나, 창 위 걷기를 끄면 임시로 앞으로 표시하던 상태도 해제됩니다.

창 감지는 Core Graphics의 창 ID·위치·크기와 Dock 시스템 창 여부를 사용합니다. Dock이 만드는 화면 크기의 투명 창은 가림 계산에서 제외하고, 실제 앱 창과 작은 Dock 영역은 반영합니다. 창 제목·화면 이미지·키 입력 내용을 수집하지 않으며 다른 앱 창을 조작하지 않습니다. 감지 프로그램이 준비되지 않으면 기본 데스크톱 동작을 유지하고 설정에 상태를 표시합니다.

**복귀 환영**은 앱 실행 중 입력이 없는 시간을 기준으로 동작합니다. 놀이·드래그·파일 작업 중이면 잠시 기다리고, 펫을 숨겼거나 대기가 오래되면 인사를 생략합니다. 창 위 걷기와 복귀 환영은 설정에서 개별적으로 켜고 끌 수 있습니다.

## 직접 실행하기

개발 환경에서 직접 실행하려면 Node.js와 npm이 필요합니다.
macOS 창 감지 프로그램을 빌드하려면 Xcode Command Line Tools도 필요합니다. `npm start`와 배포 명령은 필요한 경우 Intel·Apple Silicon 공용 실행 파일을 자동으로 빌드합니다. 배포 앱의 사용자는 개발 도구를 설치할 필요가 없습니다.

```bash
npm install
npm start
```

검증 명령:

```bash
npm run check
npm test
npm run test:electron
```

Electron 테스트는 임시 저장 폴더를 사용해 실제 창의 교감·던지기·놀이·알림·설정 변경과 재실행 복원을 확인합니다. 테스트 폴더에 화면 캡처도 저장하며 실제 사용자 데이터와 로그인 자동 실행 설정은 변경하지 않습니다.
macOS에서는 별도의 테스트 창을 띄워 창 위 착지·산책·이동 추적·최소화·닫힘을 검증합니다. 마우스 이벤트 전송 권한이 있으면 실제 클릭으로 공을 집어도 설정창이 앞으로 나오지 않는지, 공 주변의 투명 영역을 클릭하면 아래 창이 클릭되는지도 두 표시 방식에서 확인합니다. 권한이 없으면 이 클릭 검사만 건너뜁니다. 잠금·잠자기 알림은 앱 내부 테스트 이벤트로 확인하며 실제 Mac을 잠그거나 재우지 않습니다.

## 배포 파일 만들기

무료 배포용 DMG를 만들려면 다음 명령을 실행합니다.

```bash
npm run dist
```

생성 파일은 `dist/` 폴더에 저장됩니다.

```bash
dist/comtrierver.dmg
```

이 명령은 `npm run dist:mac:unsigned`를 실행합니다. unsigned 빌드이므로 다른 Mac에서 처음 실행할 때 위의 macOS 보안 경고가 표시될 수 있습니다.

## 정식 서명 배포

macOS 보안 경고를 줄이려면 Apple Developer Program 가입, Developer ID Application 인증서, Apple notarization 설정이 필요합니다.

```bash
npm run dist:mac
```

이 명령은 서명/공증 환경이 준비되지 않으면 실패하도록 설정되어 있습니다. 인증서, `.p8` 키, 앱 전용 비밀번호, Team ID 같은 민감한 정보는 저장소에 커밋하지 마세요.

권장 notarization 환경 변수:

```bash
export APPLE_API_KEY=/absolute/path/AuthKey_XXXXXXXXXX.p8
export APPLE_API_KEY_ID=XXXXXXXXXX
export APPLE_API_ISSUER=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
npm run dist:mac
```

Apple ID 방식:

```bash
export APPLE_ID=you@example.com
export APPLE_APP_SPECIFIC_PASSWORD=xxxx-xxxx-xxxx-xxxx
export APPLE_TEAM_ID=TEAMID1234
npm run dist:mac
```

리트리버 스프라이트와 macOS 아이콘 에셋을 다시 준비하려면 다음 명령을 사용합니다.

```bash
npm run assets:prepare
npm run icons:prepare
```
